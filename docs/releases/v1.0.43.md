# PlanetCreations 1.0.43 — Check for client updates

- **Check for updates:** A new button in Settings → Client checks for updates in
  the Windows, macOS and Linux clients with the built-in updater.
- **Version and last check:** The installed client version and the date and time
  of the last completed update search appear below the button. The timestamp is
  saved on this device and includes automatic and manual searches.
- **Clear update status:** See when the client is up to date, an update is
  downloading, or a restart is needed to install it. Connection failures are
  reported with a retry option; a manual download link is available when the
  automatic updater cannot download a newer release.
- Concurrent update searches share one request. Opening settings does not start
  an additional search or read or write account data.

This release is for the direct-download clients only. The Microsoft Store
version will receive its version display in a future larger update and continues
to receive updates exclusively through the Store.
