# PlanetCreations 1.0.45 — Custom Media backups without size limit

- Custom Media backups use a new `.PlanetCreationsMedia` format with no size limit. Files are named after their creation, so backups are easy to tell apart. Existing media backups can still be restored.
- Back up the available media of a creation even when some referenced files are missing, using the new "Ignore missing media" option.
- Media Manager shows whether uninstalled media can be installed again, and filters creations by media state.
- Accept images that were saved with a different image extension, such as a PNG named `.jpg`. A single unreadable file no longer stops automatic media detection.
- Restore a single backup directly from its card in the Restore tab.
- Offline Manager search, sort and filter controls match the website design and stay readable in light, dark and custom themes.
- Copy buttons, including the showcase link in the Community Manager, work in the desktop client.
- The in-game overlay shows the PlanetCreations logo again after a showcase QR code is removed.

Creation backups (`.PlanetCreations`) are unchanged.
