# PlanetCreations 1.0.32 — Desktop login hotfix

This patch restores Firebase login in the desktop client after the 1.0.31 update.

## 🔐 Reliable App Check in Electron

- Desktop windows now open the canonical `https://www.planetcreations.net` origin directly instead of passing through the non-www redirect.
- Existing 1.0.31 installations automatically recover from the redirect-triggered App Check throttle through the hosted UI, without requiring a reload shortcut or clearing user data.
- The recovery is limited to production Electron main windows, runs at most once per failed renderer session and removes its guard after receiving a valid token.
- Normal browsers, development instances and game overlays keep their existing behavior.
