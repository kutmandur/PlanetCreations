# PlanetCreations 1.0.31 — Your savefiles, understood

This release turns local Planet Coaster 2 parks and blueprints into useful, trustworthy Creation data while keeping creator-controlled presentation separate from server-verified game metadata.

## 🔎 Savefile metadata

- Parks, blueprints, autosaves and Workshop files appear immediately while their metadata is analyzed sequentially in the background.
- Results persist between client starts and are refreshed only when a file changes or when **Refresh all stats** is requested.
- The offline overview uses the in-game preview image and shows safely extracted names, tags, required DLC, costs and supported object counts.
- Parks distinguish coasters, water rides, water slides, dark rides, transport rides, flat rides and other tracked rides. Pools and combined scenery counts are included where available.
- Stored per-ride test values are displayed only when the savefile contains a sufficiently reliable record. Calculated EFN values remain hidden unless the creator enters separate overrides.

## 🎢 Attractions & Areas

- Park creators can rename or hide detected rides without changing their server-verified type.
- Custom rides, restaurants, shops and shows can be added and organized into color-coded areas.
- The public Ride List can switch between **Areas** and **Types**, while category colors and compact cards keep large parks readable.
- Replacing an attached savefile refreshes the complete verified metadata snapshot without overwriting creator-controlled Creation fields.

## 🖼️ Automatic Custom Media

- Every creation backup now creates or updates its Custom Media document, even when nothing was selected manually.
- Safe media references are detected automatically and missing referenced files are reported.
- Backup flows offer a separate matching Custom Media package so game files and media can be archived or shared independently.

## 🧭 Faster Creation setup

- The desktop Creation wizard now asks for an optional savefile first and uses its preview and metadata to prefill useful fields.
- Creator-selected information remains creator-controlled. Only server-verified DLC requirements may replace the corresponding wizard selection.
- Verified metadata is written by the backend and cannot be changed through normal client writes.

## 🪟 Client polish

- The offline metadata action now has readable contrast in both light and dark mode.
- Overlay movement, resizing and settings persistence perform less work during continuous pointer movement.
- The About the Client page now documents savefile intelligence, automatic Custom Media and the new park presentation tools.
