# PlanetCreations 1.0.46 — Park Info, Planet Zoo 2 and local backups

- Planet Zoo 2 is recognized by the overlay and Backup Manager, including its zoo saves and blueprints.
- Optionally create one backup containing a savegame and its associated media. Missing media is reported without blocking the backup; combined packages can also be imported and restored. Signed backups remain available.
- Savefile analysis is off by default and can be enabled separately for each game in Client Settings. Analysis runs locally, with an explanation of its unofficial, mod-like nature. Nerd mode is available only locally while analysis is enabled.
- Park Info replaces Attractions & Areas. Enter optional costs, construction counts and other statistics manually while retaining areas, attraction names, colours and ride lists. Empty values are hidden. These details are creator-provided, not verified metadata.
- Creation savegame uploads and the Direct Install button have been removed. Separate collaboration sharing remains available. Creations now use only PlanetCreations user tags.
- Lists load reliably on desktop and retain the end-of-list message. Returning from a Creation restores the previous scroll position.
- Improved Discord username copying, follow-state icons, report-button placement, tag entry with Enter and consistent text-length counters.
- Optional feed-pool labels are off by default. Category tooltips explain the feed mix, and the label setting explains the small pool tags.
- Updated Terms of Service and the related privacy information to reflect current features, local analysis and backup signing.
- Updated the gRPC dependency to address a security advisory and aligned build output paths with the organized workspace layout.
