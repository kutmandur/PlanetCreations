# PlanetCreations 1.0.42 — Personal themes, client settings and Planet Zoo analysis

## New

- **Personal themes:** Choose a Postimages background, card color and accent in
  Settings → Personalization. Themes follow your signed-in account in the browser
  and desktop client. Changes apply only when you select **Save theme**.
- **Colors from your background:** Get up to six color suggestions and a matching
  card/accent combination. Image analysis runs locally on request.
- **Light/dark compatibility:** An optional checkbox adapts your colors to each
  mode and previews both variants while preserving your original color choices.
- **Client settings:** Overlay behavior, keyboard shortcuts, startup and local
  file actions now live in the normal Settings page, visible only in the client.
  Streaming has its own desktop-only category.
- **Overlay automatic mode:** Enable or disable automatic display when a supported
  game is running. Manual overlay shortcuts remain available. This control requires
  an updated desktop client; Microsoft Store updates may arrive a few days later.
- **Planet Zoo statistics:** Explore animals, habitats, ancestry and genetics,
  compare potential partners and use the matchmaker from a save's statistics view.
  Analysis stays local and runs on demand; unknown or incomplete data is marked.

## Improved

- The Offline Manager uses your theme for cards and card accents. Its tabs retain
  their game colors. Signed-in users open the full Settings page from the manager;
  signed-out users can still access local client settings.
- Active Settings categories use their icon's accent as the background and remain
  readable. Theme text adjusts for contrast.
- App Check recovery handles suspend/resume, returning online and long idle periods
  more reliably, with a bounded retry for rejected tokens.
- Backup and media jobs do more work outside the main application thread, reuse
  catalogs and avoid unnecessary rescans and repeated downloads.
- Upload finalization handles retries and interrupted responses more safely and
  protects referenced files during cleanup.
- Stronger restore-path, file-size, upload, permissions and event-voting validation.
- Discord delivery and notification handling better tolerate retries and duplicate
  events. YouTube live detection includes the existing polling fallback.
- The workshop index reuses cached snapshots and moves large searches off the UI
  thread. Recovery from stale web assets avoids repeated reload loops.
- Microsoft Store builds continue to receive updates through the Store with the
  built-in updater disabled. Existing compatible desktop clients retain access to
  the online Workshop.
