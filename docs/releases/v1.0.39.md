# PlanetCreations 1.0.39 — Reliable App Check for every desktop client

This patch fixes Firebase App Check rejecting legitimate PlanetCreations desktop sessions before sign-in.

## Fixed

- The native client now presents its hosted web session as the Chromium browser it embeds instead of advertising Electron to reCAPTCHA Enterprise.
- Firebase App Check remains fully enforced; no debug token, enforcement bypass, or relaxed risk threshold is used.
- The corrected identity is applied to the shared Electron session before any application window loads, so sign-in and automatic App Check token refresh work consistently across the main window and overlays.
- Existing offline fallback and continuous hosted-site reconnection behavior remains unchanged.

## Verification

- All Electron tests pass, including new coverage for the desktop browser identity.
- All frontend tests pass and the packaged Electron web bundle builds successfully.
