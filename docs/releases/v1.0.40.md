# PlanetCreations 1.0.40 — Configurable global overlay shortcuts

This release makes the In-Game Overlay accessible without leaving Planet Coaster or Planet Zoo.

## New

- Added a global shortcut to independently show or hide the compact overlay icon.
- Added a separate global shortcut to open or close the full overlay, even while the compact icon is disabled.
- Added a shortcut recorder under **Settings → Streaming → Global overlay shortcuts**.
- Shortcut changes are validated, saved locally and activated immediately.
- Conflicting shortcuts already reserved by another application are rejected with a clear message.

## Defaults

- Overlay icon: **Ctrl/Cmd + Alt + Shift + O**
- Full overlay: **Ctrl/Cmd + Alt + Shift + P**

The modifier-rich defaults are deliberately unlikely to conflict with Planet Coaster or Planet Zoo controls.
