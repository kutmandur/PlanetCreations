# PlanetCreations 1.0.29 — Your gateway inside the game

This patch gives the PlanetCreations **In-Game Overlay** the name and identity that match its real purpose: keeping PlanetCreations close while you build.

## 🎮 The In-Game Overlay

- User-facing labels now consistently call it the **In-Game Overlay** across the client, tray menu, Creation tools, collaboration flows and help text.
- The overlay is presented first as an in-game gateway to PlanetCreations: open the full hub, follow notifications and reach collaboration controls without leaving the game.
- Creation QR codes, capture-friendly visibility and Stream Management remain useful optional extras rather than defining the overlay itself.

## 🧭 A clearer client overview

- The About the Client page now leads with the client's two core jobs: using PlanetCreations from inside the game and creating immediate backups of detected savegames.
- New client, collaboration and Stream Management features are documented in a centered layout, with streaming presented in its own optional section.
- Downloads now correctly offer separate Apple Silicon and Intel packages, and clearly identify the currently unsigned Windows and macOS installers.

## 🪟 Direct, native-feeling resizing

- Responsive selectors and floating controls now follow the client window immediately while it is being resized.
- Spring animations pause only during an active resize and resume afterwards, keeping the interface expressive without the previous delayed or “floaty” movement.
- The same correction is included in the bundled offline interface as well as the hosted UI.

Thank you for helping PlanetCreations feel at home both in and outside the game. 💙
