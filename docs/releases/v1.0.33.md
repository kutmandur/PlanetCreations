# PlanetCreations 1.0.33 — Reliable previews and login

This patch improves the final steps of publishing Creations and restores dependable sign-in for released desktop clients.

## 🔐 Desktop login recovery

- The released Electron client now waits for App Check initialization before starting Firebase Auth operations.
- If Firebase rejects a cached App Check token, the client requests a fresh token and retries the idempotent Auth operation once.
- Recovery supports both canonical PlanetCreations origins while normal browsers and unrelated Auth errors keep their existing behavior.

## 🖼️ Working media previews

- Image and YouTube previews are visible again in Creation and Event forms instead of being covered by an opaque overlay.
- Creation and Event detail galleries use the same consistent preview behavior.
- YouTube watch, short, embed and live links are recognized through the shared preview component.

## 👤 Accurate profile appearance preview

- The desktop appearance preview now mirrors the real profile banner, avatar, identity card, biography and social layout.
- The entire desktop profile is scaled proportionally into the editor preview without changing relative element sizes.

## ✅ Clear creation verification

- Server-side file verification and Creation finalization now show a dedicated animated progress dialog.
- The dialog cannot be dismissed while verification is active and closes automatically after success.
- Errors and cancellations remain visible until acknowledged, with clear service-neutral wording.
