# PlanetCreations 1.0.48 — Streaming overlay and automatic backups

- Windows and Linux X11/XWayland overlays now use a fixed, transparent monitor-sized capture window. Moving or resizing the contents no longer changes the capture dimensions. Areas outside the content pass clicks through, while controls remain interactive. The capture title is PlanetCreations Overlay.
- Linux detects supported games through their running processes, including Steam/Proton and Wine. Native Wayland retains the previous compact overlay behavior.
- Enable Auto backup on save separately for important files in Offline Manager → Backup. The client creates a local backup after the file has remained unchanged for three seconds; rapid writes are combined into the latest stable version. Keep the client running, including in the tray.
- Automatic backups appear in Restore and persist across restarts. A hover/focus popover warns that many park versions can consume significant disk space. Old versions are not deleted automatically; switching off stops future backups and allows an in-progress backup to finish.
- Backup hints render outside file cards and stay aligned when scrolling, preventing clipping.
- Installation prompts are hidden inside the desktop client, including the hosted interface.

**Compatibility:** The new features require the updated desktop client and UI. Older hosted UIs retain their existing behavior. OBS transparency depends on the selected capture method; Linux and OBS integration still need broader real-world validation.
