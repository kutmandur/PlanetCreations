# PlanetCreations 1.0.44 — Media reinstall and automatic restore

- Preserve stored media when game-folder copies are uninstalled, so they can be installed again.
- Recover missing media data and lost associations from matching local media backups.
- Restore media packages to the game's media folders and game files to their known save location. Ask for a target only when it cannot be determined reliably.
- Keep media and creation backups in their correct Restore categories and confirm unsigned backups before restoring them.
- Fix creation permissions for ordinary users, with or without attached game files.
- Refresh the homepage index until a newly created creation becomes available.

This release updates the direct-download desktop clients only. No Microsoft Store update is included.
