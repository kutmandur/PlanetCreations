# PlanetCreations 1.0.41 — Desktop mode switch and Dual Output detection

This patch restores the desktop navigation control and improves live-stream detection for Streamlabs Dual Output.

## Fixed

- The **Offline Manager** button is visible again in the hosted desktop client.
- The **Online Workshop** button remains available when using the bundled offline interface.
- Desktop detection now uses the trusted Electron preload bridge instead of the browser user agent.
- Firebase App Check compatibility remains intact because the browser-compatible user agent is unchanged.
- Streamlabs Desktop sessions using separate horizontal and vertical outputs are now recognized as live when either output is live.
- Legacy single-output Streamlabs status messages remain supported.

## Verification

- All 246 frontend tests pass.
- All Electron tests, including the new Dual Output transition coverage, pass.
- Both the hosted web bundle and Electron fallback bundle build successfully.
