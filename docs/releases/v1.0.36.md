# PlanetCreations 1.0.36 — Live local saves and Offline Nerd Mode

This patch makes local save analysis incremental and brings the full Planet Coaster 2 ride-analysis experience to the Offline Manager.

## Incremental local save analysis

- Frontier save folders are watched while the Offline Manager is active, so new, changed and deleted files appear without restarting the client.
- Rapid filesystem events are coalesced before a lightweight index refresh.
- Only a save whose modification time or file size changed is parsed again.
- Cached metadata survives desktop and cache-schema version updates; a full refresh remains an explicit user action.
- Deleted saves also remove their orphaned metadata and ride-analysis sidecars.

## Offline Nerd Mode

- Tested Planet Coaster 2 parks and autosaves can use the same animated Nerd Mode selector and full-resolution interactive chart as the Online Workshop.
- Local ride curves are stored in a browser-readable sidecar cache and refreshed only with the matching save.
- Existing metadata caches migrate only the selected park the first time its Nerd Mode is opened instead of rescanning every save.
- Calculated EFN, speed, route, elevation, acceleration and G-force channels remain available locally without consuming R2 storage.
- Blueprints deliberately remain outside Nerd Mode because they do not reliably provide the required ride-test curves.

## Compatibility

- The hosted Workshop/Offline Manager compatibility version is unchanged because older clients remain supported through feature detection.
- The Microsoft Store package is intentionally not built or published while the existing submission remains under certification.
