# PlanetCreations 1.0.35 — Reliable desktop connectivity and ride insights

This patch keeps the desktop Workshop signed in through temporary network interruptions and adds richer verified Planet Coaster 2 ride data.

## Reliable Online Workshop recovery

- Temporary Electron network suspension no longer moves the Online Workshop to an unauthenticated local origin.
- Harmless redirect cancellations no longer trigger the bundled fallback.
- The hosted Workshop retries with bounded backoff while preserving its HTTPS login session.
- A network-triggered bundled Offline Manager periodically probes the hosted interface and returns only after a successful HTTPS response.

## Planet Coaster 2 Nerd Mode

- Verified park and autosave creations can expose full-resolution tracked-ride test curves in an interactive Nerd Mode.
- Ride charts support zooming, individually toggleable channels, readable names and detailed speed, G-force, route and EFN information.
- Stored game ratings remain authoritative; calculated EFN is used only when the save contains the required curves but no final rating.
- Blueprints deliberately stay in the compact verified-stats view because native blueprint files do not provide complete test curves.

## Creation metadata and presentation

- Creation details use gallery artwork as a banner and display EFN ratings with the game's quality-based traffic-light colors.
- Verified stats, popovers and metric cards now follow the current light/dark theme with tighter centered layouts.
- Planet Coaster 2 parsing and server-side metadata verification cover additional ride details and resilient large-park handling.

## Reliability and maintenance

- Creation cleanup and scalable indexes are more resilient to deleted or duplicated records.
- Event submissions and backup processing receive stronger server-side validation.
- Legacy Tailwind opacity utilities were migrated to current syntax without changing the visual opacity.
- Browser access to private ride-analysis downloads uses a narrowly scoped R2 CORS policy.

The Microsoft Store package is intentionally not rebuilt by this tag while the existing Store submission remains under certification.
