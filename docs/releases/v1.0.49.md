# PlanetCreations 1.0.49 — Updated DLCs and Spooktacular attractions

- Adds the Planet Coaster 2 Spooktacular Pack and Planet Zoo 2 Deluxe Upgrade and Bonus Content packs to upload, profile and admin DLC lists.
- Adds verified names for all seven Spooktacular rides and classifies Horror Heights as a Dark Ride.
- Recognizes placed Walkthrough Attraction stations and displays them in their own category; scenery checkpoints are not counted as attractions.
- Keeps unverified DLC save bits unknown instead of guessing requirements.

Walkthrough detection identifies placed stations, not operating status. Existing uploaded creations require metadata refresh to receive the new classifications.
